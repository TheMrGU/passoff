# Screenshots & demos

Drop assets here and they'll be picked up by the README.

Suggested filenames (already referenced as commented placeholders in `../../README.md`):

| File | What it should show |
|---|---|
| `hero.png` or `hero.gif` | A short loop: typing `/passoff` in one client, then `/passoff-load` in another. Above-the-fold material. |
| `thread.png` | Terminal output of `passoff thread <id>` showing a multi-AI lineage chain. |
| `load.png` | An AI client (Claude Code, Cursor, Codex) reading a loaded handoff and responding to it. |

Tips for a clean demo:

- Use a clean terminal theme (no extra plugins, no personal aliases visible).
- Strip your real project name out of the prompt before recording.
- 5–10 seconds is plenty for the hero loop. Longer = lower replay rate.
- Keep file sizes small; GitHub will balk at gifs over ~10 MB.

Once you commit the assets, uncomment the matching `<!-- SCREENSHOT: ... -->` blocks in the root `README.md`.
